This page follows simulated appointment FIL2001 for patient ALICE TESTPATIENT through all four events, then shows a message with missing data. Every linked FHIR example was generated by running the sample message through the service, so the examples are exactly what it stores. All people, organisations and identifiers are fictitious; IHI, HPI-I and Medicare numbers are synthetic.

Creates:

  • ​Patient 900001: MRN (system http://example.org/fhir/sid/mrn/SIMHOSP), IHI, Medicare number, Indigenous status (PID-10 4), language (PID-15 en)
  • ​Practitioner Dr Jane SMITH, identified by HPI-I (XCN.13 NPI)
  • ​Uses Organization Simulated Hospital, which was loaded onto the server beforehand (seed/organizations.json) and is matched on facility SIMHOSP
  • ​Location Outpatient Clinic 1: physical type ro (room), managed by that Organization, with its address copied from it
  • ​Appointment FIL2001 (after S12): booked, 14 Oct 2026 09:30–10:00 +10:00

Timing only in AIS

MSH|^~\&|PAS|SIMHOSP|SIU2FHIR|POC|20261007094000+1000||SIU^S12^SIU_S12|MSG0005|P|2.5
SCH|PLC1002^PAS|FIL2002^SCHED|||||ROUTINE^Routine^HL70276
PID|1||900002^^^SIMHOSP^MR||TESTPATIENT^BOB^^^MR^^L||19751231|M
RGS|1|A
AIS|1|A|PHYSIO^Physiotherapy^LOCAL|20261016140000|||45|min
AIL|1|A|OPD^PHYSIO1^^SIMHOSP^^^^^Physio Room 1

​Appointment FIL2002 takes its times from AIS-4 + AIS-7/8, in the default time zone (Australia/Brisbane) because AIS-4 has no offset. Facility SATELLITE isn't on the server, so the service created placeholder Organization SATELLITE (tagged placeholder) for Location Physio Room 1, which therefore has no address. Patient 900002 has no Indigenous status or language because PID-10 and PID-15 are empty.

Missing data

PID|1||900003^^^SIMHOSP^MR~8003609900001230^^^AUSHIC^NI||^CHARLIE
RGS|1|A
AIS|1|A|GPCONS^General consultation^LOCAL
AIP|1|A|P9999^^ANON|ATND^Attending^LOCAL
  • ​Patient 900003: no family name, birth date or sex in PID, so gender is unknown, birthDate and an extra name carry data-absent-reason, and the IHI (which fails the Luhn check) is dropped.
  • ​AIP-3 has no family name, so no Practitioner is created: Appointment FIL2003 has a display-only participant "ANON".
  • The message is still accepted (AA) with warnings in the service log.
